Track the Smart Money. A Node.js tool that scrapes top-performing traders from DexScreener and cross-references them with Solscan to extract critical wallet metrics.
📖 Overview
The DexScreener Wallet Analyzer automates the process of finding profitable wallets on the Solana blockchain. Instead of manually checking every trader, this tool does the heavy lifting:
🔎 Scrapes DexScreener: Extracts the "Top Traders" list from any given token pair.[1]
🔬 Analyzes on Solscan: opens a browser navigating each wallet page and extracting important information.
📊 Generates Intelligence: Returns actionable data such as PnL, win rates, and coins held.
✨ Key Features
Feature	Description
🤖 Auto-Scraping	Bypasses cloudfare protections to grab profitable wallets from a pair.
🕸️ Solscan Integration	Cross-references wallet addresses to verify balances and transaction history.
📈 Filters winners by % profit and not by profit amount.
💎 Gem Detection	Creates table with coins that are held by multiple of the 'sniper' wallets.
